# CHLOE AI — contexto para continuidade

- Assistente pessoal de IA chamado **CHLOE AI**. Idioma inicial da interface: português brasileiro (pt-BR). Escopo atual: aplicativo desktop.
- O foco principal é redesenhar o frontend. Preserve o provedor de IA existente, a integração com a API e o comportamento do assistente; qualquer mudança necessária deve ser explicada.
- Direção visual: minimalista, com fundo preto puro (`#000000`).
- Elemento central: esfera formada por partículas, inspirada na imagem de referência fornecida pelo usuário, sem copiá-la exatamente. Se a referência não estiver disponível na sessão, solicite-a quando necessária.
- Enquanto o usuário fala, a esfera pulsa suavemente em azul-claro; enquanto CHLOE fala, pulsa em rosa. Somente a esfera pulsa: o texto de status abaixo dela permanece imóvel.
- A barra lateral do chat pode ser minimizada e restaurada por um controle pequeno e discreto no topo.
- Use uma voz feminina natural em português brasileiro, se o sistema de fala atual oferecer suporte.
- Após cada alteração visual concluída, reinicie ou reabra o aplicativo atualizado e mostre uma prévia ao vivo.
- Nunca versione chaves de API, tokens, certificados, memória pessoal ou outros segredos. Antes de cada publicação, confira as exclusões do Git e revise os arquivos exatos que serão enviados.

Repositório existente e privado: https://github.com/Drn66/chloe-ai (branch `main`). Não crie outro repositório nem altere sua visibilidade. Consulte `CHLOE.md` para instalação e execução no laptop; configure credenciais somente localmente.
